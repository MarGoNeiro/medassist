# CLAUDE.md — Правила работы с MedAssist

## Что это за проект

MedAssist — мобильное PWA-приложение для врачей. Справочник: препараты, МКБ-10, клинические калькуляторы. Работает офлайн, устанавливается на телефон как приложение. Стек: React + Vite + vite-plugin-pwa.

Автор проекта — Маргарита, врач-терапевт и диетолог.

---

## Критические ограничения

- **Порт 5173 занят** — там работает другой проект (адвокатская фирма). MedAssist запускается на `--port 5174`. Никогда не трогать файлы вне папки `medassist/`.
- **Это справочник, не медицинский советник** — приложение не назначает лечение, не ставит диагнозы. Везде есть дисклеймер: «Справочная информация. Дозировку определяет врач индивидуально».
- **`.env.local` не коммитить** — там URL Google Form для обратной связи.

## Навигация в приложении

- Таб-бар с 5 вкладками: Главная / Препараты / Расчёты / МКБ-10 / Избранное
- Онбординг при первом запуске — выбор специальности (32 специальности)
- Шестерёнка на главной → смена специальности
- Кнопка «Назад» перехватывается через `window.history.pushState` — чтобы браузерный Back не выкидывал из приложения
- Из Избранного навигация открывает конкретную карточку (не просто раздел)

## Дизайн

**Активная работа** — дизайн ещё дорабатывается, перед каждым визуальным изменением уточнять у Маргариты.

### Токены (index.css)
```css
--color-primary: #2563EB
--color-text: #0F172A
--color-text-secondary: #64748B
--color-text-tertiary: #94A3B8
--color-border: #E2E8F0
--color-card: #FFFFFF
--color-bg: #F8FAFC
--shadow-sm / --shadow-md
--radius-sm: 8px / --radius-md: 12px / --radius-lg: 16px / --radius-xl: 20px
```

### Что нельзя
- ❌ `system-ui` или `sans-serif` в font-family — только `'Inter', -apple-system, BlinkMacSystemFont, sans-serif`
- ❌ `border-left: 3px solid` для выделения блоков — это AI slop
- ❌ Эмодзи в UI (только если явно просит Маргарита)
- ❌ Тени с большим blur без нужды — использовать `--shadow-sm` / `--shadow-md`
- ❌ Inline-стили там, где можно CSS-класс

### Что обязательно
- ✅ Шрифт Inter (подключён в index.html через Google Fonts)
- ✅ `-webkit-font-smoothing: antialiased`
- ✅ Все кнопки с `min-height: 44px` (стандарт касания на мобильном)
- ✅ Градиент шапки: `linear-gradient(160deg, #1E40AF 0%, #2563EB 60%, #3B82F6 100%)`

## Адаптивная вёрстка

Приложение **только мобильное** — десктопная версия не в приоритете.

- Ориентир: экран 375–430px ширина
- Таб-бар фиксирован снизу, `padding-bottom: env(safe-area-inset-bottom)` для iPhone
- Страницы скроллятся вертикально, шапка `.page-header` sticky
- Нет горизонтального скролла кроме явных элементов (`.drug-tabs`, фильтры)
- Тест на реальном телефоне или DevTools мобильный режим перед сдачей

## Данные

- **Препараты** (`src/data/drugs.js`): 78 МНН, дозировки взрослые/почечная нед./пожилые/беременность, противопоказания, альтернативы, взаимодействия
- **Взаимодействия** (`drugs.js`): 50+ пар, три уровня — `danger` / `warning` / `safe`
- **МКБ-10** (`src/data/icd10.js`): 60+ кодов, планируется расширение до полного справочника
- **Калькуляторы** (`src/data/calculators.js`): 8 шкал

При добавлении препаратов: ID должны быть уникальными и последовательными; ключи в `interactions` — всегда в формате `'меньший_id-больший_id'`.

---

## Избранное

Хранится в `localStorage` (`favorites`). Структура элемента:
```js
{ id: 'drug_1', type: 'drug'|'icd'|'calc', title, subtitle, section, itemId, savedAt }
```
`BookmarkBtn` — переиспользуемый компонент, используется в DrugCard, CodeCard, CalcView.

---

## Кнопка «Ошибка в данных»

Есть в карточке препарата и карточке МКБ-кода. Открывает Google Form с предзаполненным полем (название препарата / код МКБ). URL формы берётся из `VITE_FEEDBACK_FORM_URL` в `.env.local`. Если переменная не задана — кнопка скрыта.

## Правила работы

### Перед созданием нового файла
Объяснить Маргарите: зачем файл нужен, что в нём будет, почему нельзя добавить в существующий. Только после согласования — создавать.

### Стиль текста в интерфейсе
Простой, дружеский, без канцелярита. Примеры:
- ✅ «Нашли ошибку в данных?»
- ✅ «Пока ничего нет»
- ❌ «Элементы отсутствуют»
- ❌ «Выполните поиск для отображения результатов»

### Перед крупными изменениями
Прочитать `project.md` — там контекст проекта, монетизация, roadmap.

### Коммиты
Делать только по явной просьбе. Не коммитить `.env.local`.

### Комментарии в коде
Только когда WHY неочевиден. Не описывать WHAT — хорошие имена переменных делают это сами.
